# PALETTE — Personal Color Language Tool

Eight instinct-driven choices. A palette that is entirely yours.

## Setup

```bash
npm install
npm run dev
```

## Deploy

Push to GitHub → Vercel → Deploy (zero config)

## About

PALETTE is a Swiss International Style color personality discovery tool. Users go through 8 visual rounds of color choices. Based on instinct-driven selections, a unique 5-color personal palette is generated with poetic names, a personality reading, and a downloadable palette card.

- Zero backend
- Zero API keys
- Pure frontend (React + Vite)
- All data saved in browser localStorage
